单独应用此插件时，它对项目所做的改动很少。
插件会检测某些其他插件的应用情况，并据此进行相应配置。
例如，应用 `java` 插件后，会自动配置用于构建可执行 jar 的任务。
典型的 Infra 项目至少会应用 {groovy-plugin}[`groovy`]、{java-plugin}[`java`] 或 {kotlin-plugin}[`org.jetbrains.kotlin.jvm`] 插件之一，并使用 {dependency-management-plugin}[`io.spring.dependency-management`] 插件或 Gradle 原生的 BOM 支持来管理依赖。
