[[managing-dependencies]]
= 依赖管理
include::partial$attributes.adoc[]
要管理 Infra 应用中的依赖，可以应用 {dependency-management-plugin}[`io.spring.dependency-management`] 插件，也可以使用 Gradle 原生的 BOM 支持。
前者的主要优势在于可以通过属性自定义受管理的版本，而后者通常能带来更快的构建速度。

[[managing-dependencies.gradle-bom-support]]
== 使用 Gradle 的 BOM 支持管理依赖
Gradle 允许将 BOM 声明为 `platform` 或 `enforcedPlatform` 依赖，以管理项目的依赖版本。
`platform` 依赖将 BOM 中的版本视为建议；依赖图中的其他版本和约束可能使最终采用的依赖版本不同于 BOM 中声明的版本。
`enforcedPlatform` 依赖则将 BOM 中的版本视为强制要求，并覆盖依赖图中出现的任何其他版本。

`InfraApplicationPlugin` 类提供了 `BOM_COORDINATES` 常量，可用于声明对 Infra BOM 的依赖，无需自行指定其 group ID、artifact ID 或版本，如下例所示：

.Groovy
----
include::example$managing-dependencies/configure-platform.gradle[tags=configure-platform]
----

平台依赖或强制平台依赖只会约束声明它的依赖配置（configuration）以及继承该配置的其他配置中的版本。
因此，可能需要在多个依赖配置中声明同一个平台依赖。
