[[publishing-your-application.distribution]]
== 使用 application 插件分发

应用 {application-plugin}[`application` 插件]后，会创建一个名为 `infra` 的分发包。
此分发包包含 `infraJar` 或 `infraWar` 任务生成的归档，以及用于在类 Unix 平台和 Windows 上启动该归档的脚本。
可以分别通过 `infraDistZip` 和 `infraDistTar` 任务构建 ZIP 和 TAR 格式的分发包。
要使用 `application` 插件，必须将其 `mainClass` 属性配置为应用主类的名称。
