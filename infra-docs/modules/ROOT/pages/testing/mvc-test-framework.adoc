[[mvc-test-framework]]
= MockMvc
:page-section-summary-toc: 1

Web MVC Test 框架，也被称为 MockMvc，为测试 Infra MVC 应用程序提供支持。它执行完整的 Web MVC 请求处理，但是通过 mock 请求和响应对象，而不是通过运行中的服务器。

可以直接使用 `MockMvc` 发起请求并验证响应，也可以使用
xref:testing/mvc-test-framework/server-setup-options.adoc#mvc-test-mockmvctester[`MockMvcTester`] 编写 AssertJ 断言。
xref:testing/webtestclient.adoc[WebTestClient] 也可以把 MockMvc 用作请求处理后端；
如果需要针对运行中的服务器进行端到端 HTTP 测试，可以切换后端并保留同一套 `WebTestClient` API。
