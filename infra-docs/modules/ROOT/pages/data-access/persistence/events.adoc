[[persistence-events]]
= 生命周期事件

监听器通过泛型参数声明所关注的实体类型（无法解析泛型时监听所有实体），由 `EntityManager` 在操作期间
**同步**回调，因此监听器抛出的异常会传播给调用方。监听器可通过容器自动注册（作为 `Listener` bean），
也可手动注册到 `EntityEventRegistry`。

持久化 / 更新的前置回调接收并返回 `PropertyUpdateStrategy`，决定哪些属性参与写入。
后置回调接收 SQL 参数顺序下的不可变实际属性列表；失败回调也接收该列表，
但前置回调、主键生成、版本递增或属性选择过程中失败时传入 `null`，不会暴露选择到一半的列表。
选择已完成但没有写入属性时，失败回调可以收到空列表。
失败监听器抛出的异常作为 suppressed exception 附加到原始异常，不替换原始失败。

[cols="1,3"]
|===
| 监听器 | 回调

| `PersistEventListener<T>`
| `onPrePersist(entity, metadata, strategy)` / `onPostPersist(entity, metadata, properties)` / `onPersistFailed(entity, metadata, properties, exception)`。属性列表为选中的 INSERT 列；后置回调触发时自增主键已回填。

| `UpdateEventListener<T>`
| `onPreUpdate(entity, metadata, strategy)` / `onPostUpdate(entity, metadata, properties, affectedRows)` / `onUpdateFailed(entity, metadata, properties, exception)`。属性列表为选中的 SET 列，不含仅用于 WHERE 的属性。版本字段由框架覆盖；乐观锁失败也会触发失败回调。

| `DeleteEventListener<T>`
| `onPreDelete(entity, id, metadata)` / `onPostDelete(entity, id, metadata, affectedRows)` / `onDeleteFailed(entity, id, metadata, exception)`，可获取被删除实体与主键（按 id 或示例删除时二者可能为 `null`）；后置回调可通过 `affectedRows` 获取本次删除的受影响行数。

| `PostLoadEventListener<T>`
| `onPostLoad`，实体从 `ResultSet` 装配完成后触发，可用于填充派生字段或写入缓存。

| `PostTruncateEventListener`
| `onPostTruncate`，清空表后触发（无实体实例，只有实体类与元数据）。

| `BatchExecutionListener`
| `preProcessing` / `postProcessing`，见 xref:data-access/persistence/batch.adoc[批量持久化]。

|===

== 主键生成与回调顺序

UUID 和自定义生成器在 `onPrePersist` *之后* 执行，因此前置回调可以填充生成器需要的实体属性，
也可以自行设置主键。回调结束后已有非空主键时，应用生成器不会执行。
数据库自增主键在 INSERT 执行后读取；前置回调不能依赖它已经就绪。

`onPostPersist` 在 INSERT 及主键回填处理之后调用，仍处于当前操作的事务上下文中，
不等同于提交成功通知。需要提交后执行的逻辑应使用事务同步机制。
更多说明见 xref:data-access/persistence/entity-manager.adoc#persistence-persist-id[主键与插入流程]。

[source,java,indent=0,subs="verbatim,quotes"]
----
@Component
class UserAuditListener implements UpdateEventListener<User> {

  @Override
  public PropertyUpdateStrategy onPreUpdate(User entity, EntityMetadata metadata, PropertyUpdateStrategy strategy) {
    // 校验或审计；strategy 决定哪些属性会被写回
    return strategy;
  }

  @Override
  public void onPostUpdate(User entity, EntityMetadata metadata, List<EntityProperty> properties, int affectedRows) {
    // 更新后处理
  }
}
----
