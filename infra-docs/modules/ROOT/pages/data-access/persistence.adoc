[[persistence]]
= 轻量级持久化框架 (Infra Persistence)
:page-section-summary-toc: 1

`infra-persistence` 在 xref:data-access/jdbc.adoc[JDBC] 抽象之上提供了一个轻量级的实体持久化层。
它不依赖 JPA/Hibernate，而是通过注解与运行时元数据把 Java 对象映射到关系表，并由
`EntityManager` 统一负责增删改查、示例查询、分页、乐观锁与生命周期事件。

本部分按层次拆分介绍持久化框架的各个方面：

== 配置与映射

* xref:data-access/persistence/configuration.adoc[自动配置与依赖]：引入即用、配置属性与可定制组件。
* xref:data-access/persistence/mapping.adoc[实体映射]：表 / 列 / 主键 / 版本映射、`@EntityRef` 引用实体与可插拔元数据工厂。

== 运行时 API

* xref:data-access/persistence/entity-manager.adoc[`EntityManager`]：`persist` / `update` / `updateById` / `saveOrUpdate` / `delete` / `truncate` / `find*` / `count` / `page` / `iterate` 等完整 API。
* xref:data-access/persistence/query-by-example.adoc[示例查询 (Query by Example)]：条件注解（`@Where`、`@Like`、`@In`、`@Between`、`@Subquery` 等）、注解优先级与 `ORDER BY` 解析。
* xref:data-access/persistence/update-strategy.adoc[属性更新策略]：精细控制哪些字段参与更新。
* xref:data-access/persistence/version.adoc[乐观锁]：基于 `@Version` 的并发控制。
* xref:data-access/persistence/paging.adoc[分页]：`Pageable` / `Page` / `Order`。

== 事件与批处理

* xref:data-access/persistence/events.adoc[生命周期事件]：持久化前后的监听回调。
* xref:data-access/persistence/batch.adoc[批量持久化]：自动批处理与批次监听。

== 底层构件

* xref:data-access/persistence/sql.adoc[SQL 构建与数据库平台]：`Restriction` / `Condition` 分层、`Restrictions` 工厂、`OrderSpec` 与 `Platform`。
