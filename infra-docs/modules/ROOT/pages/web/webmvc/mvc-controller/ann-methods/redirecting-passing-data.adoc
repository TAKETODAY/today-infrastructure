[[mvc-redirecting-passing-data]]
= 重定向属性

重定向时，先区分数据应该出现在目标 URL 中，还是只供目标请求临时使用：

* *目标 URL*：`RedirectView` 用视图模型中的属性展开 URI 模板；模型中没有对应属性时，使用当前请求的同名路径变量。
  默认还会把剩余的简单类型属性（包括符合条件的数组或集合）附加为查询参数。
* *目标请求的临时数据*：在控制器方法中声明 `infra.web.RedirectModel` 参数，将提示消息等数据放入其中。
  这些属性默认不参与构造 URL，而是由 `RedirectModelManager` 临时保存。参见 xref:web/webmvc/mvc-controller/ann-methods/redirect-model.adoc[重定向 Model]。

声明 `RedirectModel` 参数不会阻止普通模型属性出现在 URL 中。
如果不希望把视图模型中的属性自动附加为查询参数，可以显式返回 `RedirectView` 并调用
`setExposeModelAttributes(false)`。这不会关闭 URI 模板展开，也不会移除目标 URL 中显式指定的查询参数。
不要将不应公开的数据用于构造重定向 URL。

以下示例使用当前请求的 `+{id}+` 展开目标路径，并在目标 URL 中显式携带 `tab` 查询参数：

[source,java]
----
RedirectView view = new RedirectView("/orders/{id}?tab=summary");
view.setExposeModelAttributes(false);
return view;
----

`RedirectView` 来自 `infra.web.view`。这段代码可用于映射到 `+/orders/{id}+` 的控制器方法。
