[[mvc-config-message-converters]]
= 消息转换器

您可以通过重写 {today-framework-api}++/web/config/annotation/WebMvcConfigurer.html#configureMessageConverters(java.util.List)++[`configureMessageConverters(List)`]，
在Java配置中设置要使用的 `HttpMessageConverter` 实例，替换默认使用的实例。您也可以通过重写
{today-framework-api}++/web/config/annotation/WebMvcConfigurer.html#extendMessageConverters(java.util.List)++[`extendMessageConverters(List)`]，
在最后定制配置的消息转换器列表。

TIP: 在 Infra App 应用程序中，`WebMvcAutoConfiguration` 除了默认转换器外，还会添加它检测到的任何
`HttpMessageConverter` Bean。或者，也可以使用 `extendMessageConverters` 在最后修改消息转换器。

`FormHttpMessageConverter` 支持读取和写入 `application/x-www-form-urlencoded` 表单，
既可以使用 `MultiValueMap<String, String>` 保留同一名称的多个值，也可以使用
`Map<String, String>`；读取为普通 `Map` 时，同一名称仅保留第一个值。
multipart 写入继续使用 `MultiValueMap`，由现有的 part 转换器处理。

以下示例添加 Jackson 3 的 XML 和 JSON 转换器，并定制输出缩进。

[source,java]
----
import infra.http.converter.json.JacksonJsonHttpMessageConverter;
import infra.http.converter.xml.JacksonXmlHttpMessageConverter;
import tools.jackson.databind.SerializationFeature;
import tools.jackson.databind.json.JsonMapper;
import tools.jackson.dataformat.xml.XmlMapper;

@Configuration
public class WebConfiguration implements WebMvcConfigurer {

  @Override
  public void configureMessageConverters(List<HttpMessageConverter<?>> converters) {
    converters.add(new JacksonJsonHttpMessageConverter(
      JsonMapper.builder().enable(SerializationFeature.INDENT_OUTPUT)));
    converters.add(new JacksonXmlHttpMessageConverter(
      XmlMapper.builder(JacksonXmlHttpMessageConverter.defensiveXmlFactory())
        .enable(SerializationFeature.INDENT_OUTPUT)));
  }
}
----

使用接收 mapper 构建器的构造函数时，转换器会注册通过 `MapperBuilder.findModules(ClassLoader)`
发现的 Jackson 3 模块，并为 `ProblemDetail` 添加对应的 mixin。
XML 构建器使用 `defensiveXmlFactory()` 禁止 DTD 和外部实体解析。
