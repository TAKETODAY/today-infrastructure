[[mvc-multipart]]
= Multipart 解析器

`infra.web.multipart` 包中的 `MultipartParser` 是用于解析 `multipart` 请求（包括文件上传）的策略。
有一个默认的 `infra.web.multipart.parsing.DefaultMultipartParser` 实现。底层来源于
（Apache Commons FileUpload）


在使用 Netty 自动配置的 Infra App 应用中，框架会在没有自定义 `MultipartParser` bean 时注册默认实现，
并将其注入 `NettyRequestConfig`；自定义解析器按类型提供，无需使用特定 bean 名称。
手动配置 Netty 时，通过 `NettyRequestConfig.Builder.multipartParser(...)` 指定解析器。
通过 `ServerHttpExchange.asMultipartRequest()` 访问解析后的 `MultipartRequest`，使用 `getPart(name)` 或 `getParts()` 获取 `Part`。
